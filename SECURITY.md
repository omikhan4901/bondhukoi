# Security

BondhuKoi deals with where students are, so security problems matter a lot to us. If you
find one, thank you: please tell us privately first.

## How to report

Use **GitHub → Security → Report a vulnerability** on this repository (private
vulnerability reporting). Include what you found, how to reproduce it, and what someone
could do with it.

We'll reply within 3 days, keep you updated, and credit you below when it's fixed (if you
want). There's no money involved; this is a student project.

## Please

- Test against your own accounts only, never other students'.
- Don't read, change or delete other people's data, even to prove a point.
- Don't flood the API or try to take it down.
- Don't make the problem public until it's fixed.

## In scope

The API (`backend/`), the database rules (`supabase/`), the Android app
(`frontend/BondhuKoiApp/`) and the admin console (`admin/`). Supabase, Google Cloud and
Expo themselves are out of scope: report those to them.
